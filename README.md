# 📚 강의자료 모음

양곡고등학교(경기도 김포교육지원청 AI 중점학교)에서 사용하는 정보·컴퓨팅 교과 강의자료를 모아 공유하는 페이지입니다.

학생과 동료 교사 누구나 별도 로그인이나 프로그램 설치 없이, 아래 웹사이트 주소로 바로 접속해 자료를 확인할 수 있습니다.

🔗 **자료 바로가기:** [https://사용자이름.github.io/저장소이름/](https://사용자이름.github.io/저장소이름/)

---

## 소개

이 저장소는 다음 과목의 수업 자료(강의안, 실습 자료, 평가 자료 등)를 정리해 둔 공간입니다.

- 프로그래밍
- 데이터 과학과 머신러닝
- 소프트웨어와 생활

자료는 순서대로 학습할 수 있도록 단원별로 구성되어 있으며, 필요한 자료만 선택해서 봐도 무방합니다.

---

## 📂 자료 구성

| 구분 | 내용 | 폴더 |
|---|---|---|
| 프로그래밍 | 단원별 강의안, 실습 코드, 과제 안내 | `programming/` |
| 데이터 과학과 머신러닝 | 개념 설명 자료, 실습 노트북, 데이터셋 안내 | `data-science-ml/` |
| 소프트웨어와 생활 | 강의 슬라이드, 활동지 | `software-and-life/` |

> 위 표의 폴더 이름과 자료 목록은 실제 저장소 구성에 맞게 자유롭게 수정해서 사용하세요.

---

## 🖥️ 이용 방법

1. 위의 **자료 바로가기** 링크를 클릭합니다.
2. 원하는 과목/단원을 선택합니다.
3. 자료를 웹페이지에서 바로 확인하거나, 필요하면 인쇄(PDF 저장) 기능을 이용해 다운로드합니다.

별도의 회원가입이나 앱 설치 없이 웹 브라우저만 있으면 누구나 이용할 수 있습니다.

---

## 🔄 자료 업데이트 안내

- 자료는 학기 진도에 맞춰 순차적으로 추가·수정됩니다.
- 최신 자료가 보이지 않을 경우, 새로고침(`Ctrl+Shift+R` 또는 `Cmd+Shift+R`)을 한 번 눌러 확인해 주세요.
